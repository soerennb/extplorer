## Upgrade requirements

See the 3.1.2 changelog and [configuration migration](../configuration.md).
Custom Sendmail requires immutable operator configuration and protected path
components; old web paths never execute. Retest saved mail configuration after
upgrade. Delegated administration is bounded by permissions, home and extension
restrictions. Legacy FTPS is refused in strict mode; SFTP is the supported
authenticated alternative while a new FTPS transport is tracked separately.
